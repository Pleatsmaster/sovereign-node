# LIFE-0 operator inbox

Files appear here **only** when the operator explicitly routes genuine work
to Namariel. This inbox is a sensor surface for the LIFE-0 pulse: each new
file is a world delta, and each delta becomes a need ("unfinished user work").

## Convention (load-bearing)

- The **operator** places files here. Never the pulse, never a worker, never
  manufactured by any automation. A file in this inbox means: a human decided
  Namariel should do this.
- One file = one unit of genuine work. Name it descriptively; plain text or
  Markdown preferred.
- After the pulse forms and stages the need, the file moves to `done/`.
  Processed work is never re-sensed.

Placing a file here is an operator act with the same weight as giving a task
in chat. Do not use it for tests of the pulse itself — test fixtures live in
the test suite, not in this directory.
